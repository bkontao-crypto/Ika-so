# Intelligence et différenciation (E10)

## Objectifs
- Recommandations d'annonces personnalisées.
- Insights pour les professionnels (leads, conversion, zones chaudes).
- Différenciation : badges dynamiques, score de confiance renforcé, alertes intelligentes.

## Pistes concrètes
1. **Recommandations** : « Annonces similaires » basées sur catégorie, quartier, prix.
2. **Insights CRM** : taux de conversion par source, meilleurs créneaux, leads à relancer.
3. **Score de matching** annonce ↔ recherche sauvegardée.
4. **Alertes intelligentes** : baisse de prix, nouveau bien dans une zone suivie.

## Premier lot proposé
- Endpoint `GET /listings/:id/similar` (recommandations simples).
- Endpoint `GET /me/crm/insights` (agrégats utiles).
- Documentation des règles.

**Statut** : cadrage prêt.
